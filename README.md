# Project 6: Version Control Infrastructure

## Objective

Track Terraform infrastructure changes using Git and GitHub.

## Terraform Configuration

This project contains Terraform configuration for creating an Amazon S3 bucket.

## Version Control

Git is used to track infrastructure code changes.

The initial Terraform configuration is pushed to the `main` branch.

A separate feature branch named `niranjan-terraform-update` is used to make infrastructure changes.

## Pull Request

The feature branch is pushed to GitHub and a Pull Request is created against the `main` branch.

## Deliverable

Pull Request link demonstrating the Terraform infrastructure change.
